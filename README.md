# 🎄 Новогодняя мини-игра — v2.0

Финальная версия новогодней мини-игры, реализованной как **Telegram Mini App**  
и размещённой на **GitHub Pages**.

Проект завершён и зафиксирован как версия **2.0**.

---

## 📌 Описание проекта

Игра представляет собой простую аркаду на Canvas:
Дед Мороз ловит падающие подарки.  
Цель — набрать **30 очков**, не потеряв все жизни.

Проект создавался как:
- интерактивное поздравление
- законченный мини-продукт
- практическая работа с Canvas, JavaScript и Git

---

## 🎮 Геймплей

- 🎁 Пойман подарок → **+1 очко**
- ❌ Промах → **−1 жизнь**
- 🏆 **30 очков** — победа
- 💀 **0 жизней** — поражение
- Сложность увеличивается по мере игры

Управление:
- мышь
- сенсорный экран
- клавиатура

---

## 🔊 Звук

В игре реализована полноценная аудиосистема:

- фоновая музыка запускается по кнопке **Start**
- музыка играет по кругу
- отдельные звуки для:
  - поимки подарка
  - промаха
  - победы
  - поражения
- исключено наложение звуков
- логика проигрывания синхронизирована с состояниями игры

---

## 🧩 Техническая реализация

- JavaScript (без фреймворков)

- UI-элементы поверх Canvas
- Чёткое разделение:
  - состояния игры
  - логики
